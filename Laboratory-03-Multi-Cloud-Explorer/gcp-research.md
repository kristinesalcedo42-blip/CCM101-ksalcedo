# Google Cloud Platform (GCP)

## Brief Overview
GCP is Google Cloud Platform, launched back in 2008. Google opened up the infrastructure they use for Gmail, Youtube, and Searches to everyone else.

The thing that stands out about GCP is that its really good at data analytics and machines learning. If you're doing data or AI projects, GCP has some serious powerful tools.
## Global Infrastructure
Google has data centers everywhere. They organize it similar to other cloud providers:
- Regions: 40+ regions across the globe (as of 2024)
- Availability zones: 120+ availability zones total. 
- Premium Tier Network: Google runs their own fiber optic network which makes things fast.
## Cloud Management Console
The Google Cloud Consoles is where you do everything:
- Launch compute instances.
- Managew store buckets.
- Setup databases.
- Deploy apps.
- Monitor logs and performances.
- Manage IAM and security.
- View usage and billing
## Four (4) Core Services
### 1. Compute Engine
Google's virtual machine service. You get VMs that are basically on-demand compute power. Great flexibility, lots of machine types to choose from.
### 2. BigQuery
Its a data warehouse that can analyze massive datasets in seconds. Seriously powerful for analytics.
### 3. Cloud Storage
Object storage for files and data. Works well for everything from backups to media hosting. Its reliable and you pay for what you use. 
### 4. Cloud Run / App Engine
Serverless options for running applications. Cloud Run is container-based, App Engine is more traditional. Both let you deploy without managing servers.
## Three (3) Advantages
### 1. Data and AI leadership
If your doing data science or machine learning, GCP's tools are top-notch. BigQuery is good.
### 2. Network performance
 Google's private network is super fast. Global traffic moves quick across their infrastructure.
### 3. Kubernetes expertise
Google invented Kubernetes and their managed GKE service is really good.
## Typical Enterprise Use Cases
**Big data analytics** - Companies processing massive datasets with BigQuery

**Machine learning** - Building and deploying ML models using Vertex AI

**Data warehousing** - Centralizing company data for analytics and reporting

**Web application hosting** - Running web apps on Cloud Run or Compute Engine

**Real-time streaming** - Processing live data streams (financial data, IoT stuff, etc)

**Image and video analysis** - Using Google's vision APIs for analyzing images

**Gaming infrastructure** - Using infrastructure optimized for online games
