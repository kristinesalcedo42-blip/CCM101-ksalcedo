# Amazon Web Services (AWS) Research

## Brief Overview
AWS is like Amazon's cloud platform. It started back in the year 2006 and now it's basically one of the biggest cloud providers that exist today. They offer everything from basic computing to AI-related stuffs. The thing is you pay only for what you use.

Amazon took their own tech infrastructure that powers all their e-commerce stuff and turned it into a cloud service for everyone else to use. Now there are thousands of companies run their apps on AWS
## Global Infrastructure
AWS has data centers spread all over the world. They organize it into Regions and Avialability Zones.
- Regions: Physical locations like US East, EU West, Asia Pacific, etc. There's about the be 30+ regions now.
- Availability Zones: Multiple data centers inside each region.
## Cloud Management Console
The AWS Management Console is a web interface where you handle everything. You can:
- Set up databases.
- Manage storage.
- Launch servers.
- Monitor your infrstructure.
- Manage users and permissions.
- View bills and usage.
## Four (4) Core Services
### 1. EC2 (Elastic Compute Cloud)
This is your virtual server. It’s basically a computer in the cloud where you can run your apps. You can make it bigger or smaller depending on how much you need.
### 2. S3 (Simple Storage Service)
It’s online storage where you can store files, images, backups, and more. It’s reliable and can easily grow as you need more space.
### 3. RDS (Relational Database Service)
Managed databases like MySQL and PostgreSQL. AWS takes care of maintenance, backups, and updates for you.
### 4. Lambda
Serverless computing means you upload your code, and it runs only when needed. You don’t manage servers, and you only pay when your code runs. 
## Three (3) Advantages
### 1. Pay as you go pricing
Don’t pay for what you don’t use. AWS’s cost calculator helps you estimate your expenses. 
### 4. Huge selection of tools
They have services for almost everything. Machine learning, IoT, analytics, streaming, and more. 
### 3. Market leader
 Biggest cloud provider by market share. Lots of documentation and community help available
## Typical Enterprise Use Cases
**Web Application hosting** - Running websites and web apps at scale.

**Ecommerce Platforms** - Handling hihg traffic during scales events.

**Mobile app backends** - Powering mobile applications with backend infrastructure.

**Database management** - Storing and managing critical business data with RDS.

**Backup and disaster recovry** - Companies backup their systems to AWS.

**Machine learning projects** - Using their ML services for predicting stuff and automation.

**Data warehousing** - Using services like Redshift to analyze massive datasets.
