# Azure Research

## Brief Overview
Azure is Microsofts cloud platform. It was launched in 2010 so it's been around for a while. If you already use Microsoft stuff, Azure integrates really well.

The thing about Azure is that it works greats with Windows, Office 365, and all those Microsoft tools. So if your company is laready in the Microsoft ecosystem, Azure might feel less foreign. But they support Linux and open source stuff too.
## Global Infrastructure
Azure has infrastructure spread accross the globe too. Microsoft actually has more regions than AWS.
- Regions: Around 60+ regions/regional pairs around the world.
- Availability Zones: Multiple data centers within regions for redundancy.
## Cloud Management Console
The Azure portal is the main dashboard. Its web based interface where you:
- Create and manage virtual machines.
- Set up database and storage.
- Monitor everything.
- Configure netwrrking.
- Deploy applications.
- Manage access and security.
- Check billing and costs.
## Four (4) Core Services
### 1. Virtual Machines
These are virtual servers that can run Windows or Linux. You choose the size, operating system, and resources you need. It’s a simple way to run applications in the cloud. 
### 2. App Service
Managed platform for hosting web apps and APIs. You just deploy your code and don't worry about infrastructure. Supports .NET, Java, Python, Node.js, etc.
### 3. Azure SQL Database
Managed relational database. Automatically handles backups, updates, scaling, WOrk great if your company already uses SQL Server.
### 4. Azure Storage
Blob storage, file shares, queues, tables. Basically all the storage options you could need. Reliable and cheap for long ter mstorage.
## Three (3) Advantages
### 1. Microsoft integration
If youre already using Windows, Office, Dynamics 365, it all works together really smoothly.
### 2. Hybrid capabilities
Azure can connect to your on premises data centers.
### 3. Strong security
Microsoft puts a lot of effort into the security and compliance features. 500 companies use it.
## Typical Enterprise Use Cases
**Office 365 integration** - Using Azure alongside Microsoft 365 services.

**Data Analysis** - Using tools likes Azure Synapse for big data processing.

**Database management** - SQL server workloads moving to Azure SQL.

**AI and machine learning** - Azure has decent AI services for building smart applications. 

**Business applications** - Running Dynamics 365 and other Microsfot business apps.

**Disaster Recovery** - Backup plan if your main datacenter goes down.

**Migrating from on premises** - Companies moving their servers and apps to the cloud.
