# Reflection

Azure is honestly good. At first, I thought it was basically AWS for Microsoft Users only. But after looking into it more, I noticed how well everything connect, especially with Active Directory and Microsoft 365. It feels easier when you already uses Microsoft tools. AWS is bigger, but Azure felt more natural and easy to navigate, which was something I did not expect before.

AWS, Azure, and GCP are looks all similar when you look the names. EC2, Virtual Machines, and Compute Engine basically give you a server in the cloud. Storage, databases, and identity services works in similar ways too. Thei pricing is also mostly pay as you go. The main difference is their strengths. AWS is more all around, Azure is strong with Microsoft, and GCO is good for data and AI

The biggest thing i learned is that the best cloud platform depends on the business. A startup might care miore about the cost and getting online fast. A university that already Microsoft would probably be better with Azure. A company doing lots of AI or data work could choose GCP. Even if a platform looks better, it can still be a bad choice if the team does not know how to use it. Budget and skills matters too.

I learned that there is no platform that is simply the best for everyone. You have to listen first, then recommend something that actually fits. Cost matters, but training, vendor lock in, future growth, and switching costs matter too. I also learned that being honest about weaknesses builds more trust. It is better to admit a problem than pretend everything is perfect.

My portfolio started with almost nothing, but now it shows real progress. I created comparison tables, client recommendations, and notes, and the checkpoint files helped me improve it.
