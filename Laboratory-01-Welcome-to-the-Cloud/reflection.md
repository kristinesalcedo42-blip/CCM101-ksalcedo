# Reflection

At first, I was a little confused when I started using the Linux Playground because I was not used to the commands. I learned how to create a new user and give it sudo access. I also learned how to check my username, working directory, and hostname using simple commands. Making the [system-information.md](system-information.md) files was easy after I understood what information I needed to put. I made some small mistakes with the commands,  and i even restarted it many times but I was able to fix them and continue.

Creating the ´Notes´, ´Reports´, and ´Screenshots´ folders also helped me understand how files are organized in Linux. I learned how to make a Markdown file and view it directly in the terminal. At first, I was not sure if I was doing it right, especially when using ´Nano´, I thought i did something wrong. This helped me become familiar with the Linux terminal and its basic commands.
