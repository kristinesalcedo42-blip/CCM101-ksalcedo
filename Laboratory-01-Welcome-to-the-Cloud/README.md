# Laboratory 01 - Welcome to the Cloud 

## Mission Overview
This laboratory activity introduced the basics pf cloud computing and basic Linux commands in a cloud environment. It allowed us to explore cloud platforms and understand how cloud services can be used for different computing tasks.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Perform
- Opened KillerCoda Linux Playground.
- Created a new Linux user(ksalcedo) with Bash, home directory, and sudo access.
- Used Linux commands to check system information.
- Created `Notes`, `Reports`, and `Screenshots` directories.
- Inside the `Notes` directory, I created a markdown named `about-me.md`.
- Created and organized files and folders for the laboratory.
- Created public GitHub.
- Uploaded and Update the repository with the required files and screenshots.

## Linux Commands Used

```bash
adduser ksalcedo
usermod -aG sudo ksalcedo
sudo - ksalcedo
su -ksalcedo
whoami
pwd
hostname
cat /etc/os-release
uname -r
lscpu
free -h
df -h
nano system-information.md
cat system-information.md
mkdir Notes Reports Screenshots
ls
cd Notes
nano about-me.md
cat about-me.md
ls -R $HOME
```

## Skills Learned
I learned how to use basic Linux commands to check system information and manage files and folders. I also learned how to create and edit files using the terminal.
